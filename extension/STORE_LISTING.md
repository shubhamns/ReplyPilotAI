# Chrome Web Store listing (draft)

## Name
ReplyPilot AI

## Short description
Fix grammar, rewrite, translate, summarize, and reply with AI — without leaving the page.

## Detailed description
ReplyPilot AI is an on-page writing assistant for Gmail, LinkedIn, Slack, WhatsApp Web, and any site with text.

Select text, then:
• Generate a natural AI reply
• Fix grammar and spelling
• Rewrite in Professional, Friendly, Short, Formal, or Clear tone
• Translate into your target language
• Summarize long messages

Use the floating ✨ AI button, right-click menu, or extension popup. Copy or replace text in one click.

Your OpenAI key stays on your backend — never inside the extension.
