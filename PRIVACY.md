# Privacy Policy — ReplyPilot AI

**Last updated:** August 8, 2026

ReplyPilot AI helps you rewrite, translate, fix grammar, summarize, and reply to text selected on websites.

## What we process

When you run an AI action, selected text and your OpenAI API key (from Settings) are sent to **your configured backend URL**, which calls OpenAI. The key is stored in `chrome.storage.local` on your device only and is not committed to the repository.

## What we do not do

- We do not ship OpenAI keys in the extension source, backend `.env`, or git.
- OpenAI keys are entered only in the extension Settings UI (BYOK).
- We do not sell user content.

## Storage on your device

Theme, API URL, and OpenAI API key via `chrome.storage.local` / `chrome.storage.sync` (theme).

## Third parties

AI processing is performed by OpenAI when your backend calls their API with your key.
